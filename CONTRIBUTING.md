# Contributing

Contributions should improve defensive accuracy, detection, hardening, testing, or documentation.

Requirements:

- no credential extraction code
- no real credentials or production secrets
- use synthetic examples
- cite primary Microsoft or standards documentation
- preserve PowerShell 5.1 compatibility unless a version change is agreed
- include error handling
- include Pester coverage for behavior changes
- pass PSScriptAnalyzer and GitHub Actions
- explain compatibility impact and rollback

Use feature branches and pull requests. Keep commits focused.
