# Disclaimer

This repository is for authorized defensive security research, configuration validation, and education.

The scripts can change Windows security settings when explicit hardening switches are supplied. Test all changes in an isolated lab and staged deployment ring. Back up configuration, document application dependencies, and use the same management authority for deployment and rollback.

No guarantee is made that every control is appropriate for every Windows edition, server role, application, authentication provider, or operational environment.

The carousel images contain synthetic lab-style credentials visible in screenshots. Do not reuse those strings as real passwords.
